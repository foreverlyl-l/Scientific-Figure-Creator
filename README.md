Scientific Figure Builder & Reviewer 是一组面向 Codex 的科研图技能，用于把已有科研图初稿或参考图，逐步重建为结构清晰、可编辑、可审核的 PowerPoint 科研图。

仓库包含两个配套 skill：

- `scientific-figure-builder`：负责科研图重建和施工期审核；
- `scientific-figure-reviewer`：负责仅显式调用、只读的独立终审。

## 现在能做什么

- **理解已有初稿：** 从科研表达角度识别面板、标题、标签、公式、图例、输入输出、箭头、反馈路径、重复对象和阅读顺序，而不是把参考图简单视为一张平面图片。
- **建立可追踪结构：** 把原图拆分成带稳定 ID 和父子关系的语义 block，并建立 object inventory，使缺失、重复、错误替换和未完成内容在审核过程中保持可见。
- **在 PowerPoint 中重建：** 将文字、公式、矩形、圆形、表格、箭头、连接线、简单坐标轴和色块等内容重建为可编辑的 PowerPoint 原生对象。
- **诚实处理复杂内容：** 对复杂曲线图、科研图像、设备渲染、纹理图标和自定义几何使用可追踪的原子裁剪素材，或明确标记为 deferred，避免用低质量通用形状替代。
- **管理与复用素材：** 为裁剪素材记录稳定 ID、原图区域、父级 block、语义角色、别名和放置位置；语义等价的重复素材可以复用同一份规范源文件。
- **逐块施工与审核：** 每个 block 在被接受前都需要与参考图对应区域进行对照，检查对象完整性、箭头方向、连接关系、文字、公式、分组、顺序和图例。
- **执行独立终审：** 用户明确调用 `scientific-figure-reviewer` 后，先逐块检查，再检查整图关系；问题分为 Level 1 语义问题和 Level 2 视觉细节问题。
- **区分原图错误：** 已经存在于参考图中的逻辑或语义问题会被标记为 `source-error`，不会被错误归因于重建过程。

当前流程可以形成可编辑 PPTX、原子素材目录、语义 block map、object inventory、asset manifest、施工报告和独立终审报告。

## 现在不能做什么

- 项目不自带 PowerPoint 绘图后端，实际施工和渲染依赖 Codex 运行环境中已有的 PowerPoint 能力。
- 当前需要从一张已有初稿或参考图开始，尚未包含自动初稿绘制和自动图片高清化。
- 不保证像素级完全复现。低分辨率参考图和高度复杂的视觉对象可能继续作为可追踪图片素材存在，或被明确延期；目前也不支持可编辑 `.drawio` 交付。

## 什么场景下表现较好

- 论文配图、模型示意图、工作流、过程图、架构图和框图；
- 已有较清晰视觉初稿，且面板、标签、箭头、公式和阅读顺序相对明确的项目；
- 同时包含可编辑几何结构和少量复杂图片元素的科研图；
- 需要交付可编辑 PowerPoint，而不是单张扁平图片的任务；
- 重视语义正确、素材可追踪、中间审核以及强模型或人工判断的项目。

## 后续计划

- 自动化图片高清化，同时保留原始素材，并对科研证据图实施专门保护；
- 根据文字需求、结构化规范或粗略草图自动绘制科研图初稿；
- 支持可编辑的 draw.io 重建与交付。

## 许可证范围

仓库许可证适用于插件、skills、脚本和文档。  
它不授予第三方参考图的使用权，也不会自动判定用户生成的 PPTX 文件和素材采用何种许可证。
